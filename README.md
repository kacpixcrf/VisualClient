**Visual Client** is a modern, lightweight, and blazingly fast Minecraft launcher. Built from the ground up with smooth performance, minimalist design, and low resource usage in mind — no more bloated launchers eating up hundreds of megabytes of RAM!

---

## About the Project

Traditional launchers built on frameworks like Electron can consume vast amounts of system resources before you even launch the game. **Visual Client** prioritizes maximum efficiency:
- **Powered by Rust, Tauri & Vue:** Instant startup times with minimal RAM and CPU footprint.
- **Glassmorphism Interface:** Elegant dark mode design featuring smooth animations and dynamic lighting effects.
- **Convenience & Security:** Seamless account integration and automated background updates.

---

## Features

- **Modern UI:** Refined Glassmorphism layout, frameless window with a custom title bar, and an intuitive user interface.
- **Blazing Performance:** Native lightweight performance powered by Rust — the launcher won't slow down your PC while playing.
- **Account Management:** Secure authentication using official Microsoft OAuth as well as full Offline mode support. Effortless profile switching.
- **Custom Game Instances:** Create and run multiple independent Minecraft instances with isolated directories for mods, shaders, and configs.
- **Automatic Updates:** Built-in update system with cryptographic signature verification — always stay on the latest version without manual reinstallation.
- **Multi-language Support:** Available in English and Polish.
